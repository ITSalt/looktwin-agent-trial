1) **Does not mask empty unquoted values**  
   The regex requires at least one character for unquoted values (`[^\s,;&}\]]+`), so empty values are skipped.

   - Input: `password=`
   - Actual output: `password=`
   - Expected: `password=***`

2) **Consumes trailing punctuation as part of unquoted value, changing non-secret text**  
   The unquoted value pattern allows characters like `)` and `.`, so punctuation adjacent to the value can be removed when replaced.

   - Input: `failed auth (token=abc)`
   - Actual output: `failed auth (token=***`
   - Expected: `failed auth (token=***)`

   (Same issue with e.g. `token=abc.` becoming `token=***`.)
